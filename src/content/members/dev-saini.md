  - title: ZENsilent
    description: |-
      ZENsilent automatically switches your phone to Silent Mode based on your location or schedule, so you don't have to remember it before entering a class, meeting, library, or office.
      New Features
      🗺️ Map-based Geofence Setup
      You can now select locations directly on a map using OpenStreetMap (OSMDroid) instead of entering coordinates manually. There's also a Current Location button to create a geofence instantly.
      📞 Urgent Call Override
      This was one of the most challenging features to build.
      Even when your phone is in Silent Mode, calls from selected whitelisted contacts are allowed to ring, while all other calls remain silent. This helps ensure you never miss an important call from family or close contacts while still avoiding unnecessary interruptions.
      Other Features
      • 📍 Automatic Silent Mode using Geofencing (custom radius)
      • 🗓️ Schedule Silent Mode (Today, Tonight & Tomorrow)
      • ⏱️ Timer-based Silent Mode
      • 👥 Whitelist Contact Management
      • 🎨 Modern UI built with Jetpack Compose
      • 🔒 Uses OpenStreetMap instead of Google Maps APIs
      Tech Stack
      Kotlin • Jetpack Compose • Android Geofencing API • OpenStreetMap (OSMDroid) • Room Database • MVVM
